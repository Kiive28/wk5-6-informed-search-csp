# Reading Links — Informed Search, A*, and CSP

## Heuristic / Informed Search and A*

- [Red Blob Games — Introduction to A*](https://www.redblobgames.com/pathfinding/a-star/introduction.html) — the best interactive, visual explanation of A* available online. Highly recommended starting point.
- [Amit's A* Pages (Stanford mirror)](https://theory.stanford.edu/~amitp/GameProgramming/index.html) — deeper companion material to the Red Blob Games guide (heuristics, grid variations, implementation notes).
- [GeeksforGeeks — Informed Search Algorithms in AI](https://www.geeksforgeeks.org/artificial-intelligence/informed-search-algorithms-in-artificial-intelligence/)
- [GeeksforGeeks — A* Algorithm and its Heuristic Search Strategy](https://www.geeksforgeeks.org/artificial-intelligence/a-algorithm-and-its-heuristic-search-strategy-in-artificial-intelligence/)
- [GeeksforGeeks — A* Search Algorithm (DSA version, with code)](https://www.geeksforgeeks.org/dsa/a-search-algorithm/)
- [GeeksforGeeks — Heuristic Function in AI](https://www.geeksforgeeks.org/artificial-intelligence/heuristic-function-in-ai/)
- [GeeksforGeeks — Informed vs. Uninformed Search](https://www.geeksforgeeks.org/artificial-intelligence/difference-between-informed-and-uninformed-search-in-ai/)
- [Wikipedia — A* search algorithm](https://en.wikipedia.org/wiki/A*_search_algorithm)

## Constraint Satisfaction Problems (CSP)

- [GeeksforGeeks — Constraint Satisfaction Problems (CSP) in AI](https://www.geeksforgeeks.org/artificial-intelligence/constraint-satisfaction-problems-csp-in-artificial-intelligence/)
- [GeeksforGeeks — Backtracking Search and Its Role in Solving CSPs](https://www.geeksforgeeks.org/artificial-intelligence/explain-the-concept-of-backtracking-search-and-its-role-in-finding-solutions-to-csps/)
- [GeeksforGeeks — Introduction to Backtracking](https://www.geeksforgeeks.org/backtracking-introduction/)
- [Wikipedia — Constraint satisfaction problem](https://en.wikipedia.org/wiki/Constraint_satisfaction_problem)
- [University of Toronto — Backtracking Search lecture slides (PDF)](http://www.cs.toronto.edu/~hojjat/384w09/Lectures/Lecture-04-Backtracking-Search.pdf) — useful for seeing forward checking worked through slide-by-slide.

## Textbook (the standard reference for both topics)

- Russell, S. & Norvig, P. — *Artificial Intelligence: A Modern Approach*
  - [Official book site (Berkeley)](https://aima.cs.berkeley.edu/) — sample chapters, pseudocode, and reference code implementations in multiple languages.
  - Relevant chapters: **Ch. 3** (Informed / heuristic search, A*) and **Ch. 6** (Constraint Satisfaction Problems).
  - [Ch. 5/6 CSP chapter draft (PDF, older edition numbering)](https://aima.cs.berkeley.edu/newchap05.pdf)

## How to use these

- Start with the Red Blob Games page for A* and the GeeksforGeeks CSP
  overview for CSP — both are visual and example-driven.
- Use the AIMA textbook chapters if you want the formal definitions and
  proofs (e.g. why admissible heuristics guarantee optimality).
- Everything you strictly need for this assignment is already summarized
  in `../01_Informed_Search_A_Star/guide.md` and `../02_CSP/guide.md` —
  treat these links as optional deepening, not a prerequisite.
